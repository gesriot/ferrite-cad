# §25C — выбор и перемещение вершины мышью

В редакторе **Create sketch + Extrude…** или **Edit Sketch …** нажмите рядом
с существующей вершиной и перетащите её. Контур, строка X/Y в mm и подпись
`Vertex N` показывают один черновик. Светло-жёлтая точка и номер строки — выбор;
голубое кольцо — hover. Радиус выбора — 9 экранных points независимо от Fit/масштаба
и DPI; среди кандидатов выбирается ближайший, при равенстве — первый в сохранённом
порядке. Невидимые за clip-границей вершины не участвуют в выборе.

## Жест и точность

- Выбор без движения не меняет числа, IDs или историю. В незамкнутом новом
  контуре выбор существующей вершины не добавляет ещё одну. Свободный click
  по-прежнему добавляет точку с прежней точностью 0.001 mm, максимум 256 точек.
- Drag использует смещение указателя от первоначального нажатия и масштаб на
  момент нажатия. Смещение места захвата от центра вершины сохраняется, скачка
  к указателю нет. Snapping/округления drag нет. Незатронутые вершины и оси
  сохраняют точные строки числовых полей, включая больше трёх знаков после запятой.
  Для заданного точного результата можно вводить X/Y полями; они меняют тот же draft.
- Preview обновляется при движении. Release, включая release за canvas внутри
  окна, завершает **один** Undo/Redo шаг. Возврат в исходную точку — no-op.
  Press/move/release, полученные одним кадром, также завершают жест; последующий
  hover не меняет его конечную координату. События обрабатываются по порядку:
  release первого жеста не поглощает следующий press в том же кадре; несколько
  завершённых жестов дают отдельные шаги, даже если итоговый контур вернулся к
  состоянию начала кадра. Перекрывающее canvas окно защищено от правки насквозь.
- Escape, потеря фокуса окна, исчезновение указателя (`PointerGone`) или потеря
  нажатой primary button без release отменяют жест и восстанавливают исходный
  State. Undo/Redo при этом не меняются. Release отменённого жеста не добавляет
  точку и не начинает другую правку. Новый primary press начинает новый жест.
- Во время захваченного жеста остальные поля/кнопки правки временно недоступны.
  Вне жеста canvas не перехватывает числа, Escape в поле или scrolling таблицы.
  Fit/Reset меняют только вид, не модель/историю. История остаётся ограниченной
  128 состояниями; preview не накапливает состояния на каждом кадре.

Недопустимый preview остаётся видимым с диагностикой прежней общей
`PolygonExtrusion`/`SketchChoice` policy. Coincidence, crossing, вырождение,
не-конечные/выходящие за диапазон координаты и смена winding сохранённого Sketch
не публикуются. После release такой черновик можно исправить точными полями или
Undo; Save отсутствует при отказе policy и недоступен во время жеста.
Некорректную числовую строку нужно исправить полем, прежде чем canvas снова сможет
отобразить соответствующий числовой контур. Kernel/rebuild не вызывается на pointer events.

## Сохранение и CLI

Для сохранённого Sketch вершина по-прежнему означает **start persisted curve**,
номер — только её место в неизменной последовательности. Отдельного vertex UUID
нет; предыдущий end меняется общим jobs-маршрутом. Нельзя добавлять, удалять или
переставлять сегменты сохранённого Sketch. Height, metadata, остальные SQL cells,
attached source claims и object/curve/reference UUID сохраняются по §25B.

Save Cancel/Failed, worker refusal и отмена сохраняют draft и принятую сцену.
Generation/version/source/Keep guards и обычный async Open не менялись.
Тот же результат доступен агенту через прежние
[create-sketch-extrude](sketch-extrude-create.md) и
[edit-sketch-copy](edit-sketch-copy.md) JSON requests с конечными координатами.
Новых CLI-команд, JSON полей, jobs/API, document schema или FFI нет.
[Рецепт L 60→80](edit-sketch-copy.md#исполняемый-рецепт) остаётся исполняемым:
после двух drag на 20 mm вправо или ввода тех же координат получается
80×40×10, volume 20000 mm³. Между отдельными командами нет нового snapshot guard.

Не входят constraints/snapping, новые curves, in-place Save и persistent undo.
[Исполненные проверки и GUI](sketch-vertex-drag-verification.md).
