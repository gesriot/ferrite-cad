# Source ownership for the canvas removal

Base `9a0b0fbbe5f7215b7db944b8b4a16e5c56d05dd9`. Lines are physical lines in the base file, including tests, comments and blank lines. Each file has one proposed disposition. A mixed file stays in place unless its remaining work has a better owner. The scope column identifies removable blocks within a surviving file. Counts here are file sizes, not summed estimates of additions.
